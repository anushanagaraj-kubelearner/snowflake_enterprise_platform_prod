Snowflake Enterprise Platform - Production Deployment
Overview

This repository contains SQL deployment scripts used to provision and validate Snowflake infrastructure in a controlled and repeatable manner. The scripts are organized according to the deployment lifecycle, from environment setup through application deployment and validation.
